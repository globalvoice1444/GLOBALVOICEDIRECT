======================
==-  INTRODUCTION  -==
======================

This widget was created to allow Telinta's customers to embed the WebRTC dialer into their web site in addition to access from account and customer self-care portals.

======================
==- CONFIGURATION  -==
======================

    1. Place the files on your web server.

    2. Edit the config.js files according to your needs. You can see descriptions of the available settings in the file.

    3. Integrate the rate calculator widget into your web site.
